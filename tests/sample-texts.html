使い方 (How to use):
Hover your mouse over any Japanese sentence below and press Ctrl + Shift together. A popup will appear showing the grammar patterns detected in that sentence!

Longer Sentences

私は毎朝6時に起きて、朝ご飯を食べてから、会社に行きます。

週末は友達と一緒に買い物に行ったり、映画を見たりします。

もし明日雨が降らなければ、ハイキングに行くつもりです。

News-Style Text N4

Tip: Try changing the JLPT level settings by clicking the extension icon in the Chrome toolbar. Disable N5 patterns if you want to focus only on N4 and above!

About This Test Page

This page contains various Japanese sentences with different grammar patterns from JLPT N5 and N4 levels. Use this page to test bunpochan's grammar detection capabilities. Each sentence contains multiple grammar patterns that should be identified when you press Ctrl+Shift.

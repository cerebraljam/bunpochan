🧪 Bunpochan Pattern Matching Tests

What this does:

This test suite verifies that the grammar pattern database correctly identifies patterns in Japanese sentences.

It tests sample sentences from all JLPT levels (N5-N1) and reports:

  • ✅ Patterns that are correctly detected
  • ❌ Patterns that should be detected but aren't
  • 📊 Overall success rate

Open the browser console (F12) to see detailed test results.
